# КиноДом

Учебное десктопное приложение о фильмах на React и TypeScript. Проект находится в разработке.

## Что реализовано

- Главная страница с Header, переключаемыми постерами Hero, преимуществами и Footer.
- Каталог популярных фильмов из TMDB с состояниями загрузки, ошибки и пустого ответа.
- Диалог с шестью популярными фильмами и статичными примерами актёров: открытие, очистка поля, закрытие по Escape и клику на фон.
- Локальные WebP-изображения и плавное появление постеров после загрузки.

Ввод в диалоге пока не выполняет поиск. Страница фильма, сериалы, жанровые ряды и маршрутизация ещё не реализованы. Часть элементов интерфейса остаётся заглушками. Мобильная версия пока не входит в текущий объём.

## Стек

React 19, TypeScript 6, Vite 8, Redux Toolkit / RTK Query, CSS Modules и Oxlint. Менеджер пакетов — npm.

## Локальный запуск

Используйте Node.js 24 и npm. После клонирования репозитория:

```sh
npm ci
```

Создайте `.env.local` в корне приложения по примеру `.env.example`. Укажите свой TMDB API Read Access Token в `VITE_TMDB_READ_ACCESS_TOKEN` без префикса `Bearer`; адрес API уже указан в примере.

```sh
npm run dev
```

Без действующего токена интерфейс запустится, но каталог не сможет получить данные TMDB.

## Проверки и сборка

```sh
npm run lint
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт production-сборку в `dist`. `preview` запускает локальный просмотр этой сборки.

## Структура

```text
src/
  app/       # сборка приложения, store и общие стили
  widgets/   # Header, Hero, Benefits, Footer
  features/  # диалог поиска
  entities/  # фильмы и люди, карточки и запросы
  shared/    # UI-компоненты, основа API, шрифты и иконки
```

## Переменные окружения

`.env.local` и другие файлы с локальными значениями исключены из Git. В репозитории хранится только `.env.example` без токена.

Переменные `VITE_*` встраиваются в клиентскую сборку и доступны посетителю сайта. Они не подходят для хранения серверных секретов. При сборке на Netlify эти переменные нужно задать в настройках окружения проекта.

## Netlify

В репозитории есть `netlify.toml`: сборка запускается из корня командой `npm run build`, публикуется папка `dist`, используется Node.js 24. Автоматический деплой требует подключения репозитория к Netlify и настройки переменных окружения.

## Данные и учебные материалы

Данные фильмов и изображения каталога предоставлены [TMDB](https://www.themoviedb.org/). Проект не одобрен и не сертифицирован TMDB.

Исходное учебное задание: [movie-app-template](https://github.com/webistomin/movie-app-template). Приложение выделено из учебного репозитория [education-frontend](https://github.com/EugeneSysoev/education-frontend).
