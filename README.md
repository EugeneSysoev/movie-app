# КиноДом

Учебное десктопное приложение о фильмах на React и TypeScript. Проект находится в разработке.

## Что реализовано

- Главная страница с Header, Hero с будущими премьерами TMDB для России, преимуществами и Footer. Hero показывает до трёх фильмов с постерами и переключается через Swiper.
- Загрузка, ошибка с повтором запроса, пустой ответ и ошибка отдельного постера в Hero.
- Каталог из пяти жанровых рядов: Комедии, Драмы, Фэнтези, Триллеры и Детективы. Жанры и фильмы загружаются через TMDB; каждый ряд показывает четыре карточки и до десяти фильмов с циклическим перелистыванием Swiper по одной карточке.
- Загрузка, ошибка и пустой ответ каталога с повтором запроса; заглушки отсутствующих или не загрузившихся изображений. «Посмотреть всё» пока недоступно.
- Диалог со статичными примерами актёров: открытие с фокусом в поле, ввод и очистка, закрытие по Escape и клику на фон, возврат фокуса на кнопку поиска.
- Локальные фоновые изображения и плавное появление постеров после загрузки.
- Подготовлена основа API: локальная OpenAPI-схема TMDB, генерация типов и хуков через Orval, Axios и TanStack Query.

Ввод в диалоге пока не выполняет поиск. Страница фильма, сериалы и маршрутизация ещё не реализованы. Часть элементов интерфейса остаётся заглушками. Мобильная версия пока не входит в текущий объём.

## Стек

React 19, TypeScript 6, Vite 8, Swiper, Orval, TanStack Query, Axios, CSS Modules и Oxlint. Менеджер пакетов — npm.

## Локальный запуск

Используйте Node.js 24 и npm. После клонирования репозитория:

```sh
npm ci
```

Создайте `.env.local` в корне приложения по примеру `.env.example`. Укажите свой TMDB API Read Access Token в `VITE_TMDB_READ_ACCESS_TOKEN` без префикса `Bearer`; адрес API уже указан в примере.

```sh
npm run dev
```

Для загрузки премьер Hero необходимы действующий токен и доступ к TMDB. При ошибке запроса секция показывает сообщение и кнопку повтора.

## Проверки и сборка

```sh
npm run lint
npm run test:catalog
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт production-сборку в `dist`. `preview` запускает локальный просмотр этой сборки.

`test:catalog` проверяет подготовку карточек: отбор и порядок десяти фильмов, исключение дублей, соответствие жанров, отсутствующие изображения и рейтинги. Используется встроенный тестовый модуль Node.js 24.

Каталог использует `/discover/movie` с фильтром жанра, языком `ru-RU` и сортировкой по популярности. Названия жанров приходят из `/genre/movie/list`. В карточках используются горизонтальные изображения и рейтинги TMDB; отсутствующие данные не заменяются демонстрационными значениями.

Для повторной генерации API из локальной схемы `src/shared/api/schema.json`:

```sh
npm run generate:api
```

Результат находится в `src/shared/api/generated`. Сгенерированные файлы не редактируются вручную.

## Структура

```text
src/
  app/       # сборка приложения и общие стили
  widgets/   # Header, Hero, Benefits, MovieCatalog, Footer
  features/  # диалог поиска
  entities/  # фильмы и люди, карточки и локальные модели
  shared/    # UI-компоненты, основа API, шрифты и иконки
```

## Переменные окружения

`.env.local` и другие файлы с локальными значениями исключены из Git. В репозитории хранится только `.env.example` без токена.

Переменные `VITE_*` встраиваются в клиентскую сборку и доступны посетителю сайта. Они не подходят для хранения серверных секретов. При сборке на Netlify эти переменные нужно задать в настройках окружения проекта.

## Netlify

В репозитории есть `netlify.toml`: сборка запускается из корня командой `npm run build`, публикуется папка `dist`, используется Node.js 24. Автоматический деплой требует подключения репозитория к Netlify и настройки переменных окружения.
